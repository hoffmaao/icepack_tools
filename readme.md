# icepack_tools

A support package for [icepack](https://github.com/icepack/icepack) and
[icepack2](https://github.com/icepack/icepack2).

## Install

```bash
pip install --no-deps -e .
```

Requires `firedrake`, `icepack` and `icepack2`, which it does not install for
you.

## Tests

```bash
python -m pytest test/ -q
```
