# icepack_tools

A support package for [icepack](https://github.com/icepack/icepack) and
[icepack2](https://github.com/icepack/icepack2).  The layered dual model
comes from [multilayer](https://github.com/hoffmaao/multi-layer): its
function space, momentum balance and the basal and interlayer closures
are that package's, and this one adds the regularisation, the floors and
the friction laws around them.  Install multilayer first.

```bash
pip install --no-deps -e .
```
