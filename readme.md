# icepack_tools

A support package for [icepack](https://github.com/icepack/icepack) and
[icepack2](https://github.com/icepack/icepack2).  It holds the dual
model's building blocks for one layer or several: the mixed function
space, the momentum balance, the basal and interlayer closures, and the
regularisation, floors and friction laws around them.  It needs only
Firedrake and icepack2.  The layered research model
[multilayer](https://github.com/hoffmaao/multi-layer) is built on it.

```bash
pip install --no-deps -e .
```
